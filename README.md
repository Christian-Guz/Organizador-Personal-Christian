### Práctica integradora: Git, GitHub y entorno de trabajo

# Objetivo principal: aplicar de forma integrada el flujo de preparación, versionamiento y colaboración de un proyecto.

Tecnologías utilizada: Visual Studio Code, Git y GitHub

## Pasos de instalación
1. Entrar al repositorio del GitHub del Dueño
2. Realiza un FORK del repositorio del Dueño
3. En la terminal de VSC, realiza un CLONE con el link de la copia del repositorio que tienes
4. Crea una RAMA (BRANCH) para realizar tu aportación.
5. Realiza un PUSH a tu repositorio en github
6. Realiza un Pull Request y espera aceptación
7. Sincroniza tu FORK

## Dependencias
- Visual Studio Code
- Python 3.10.11
- Git 2.52.0
- GitHub
